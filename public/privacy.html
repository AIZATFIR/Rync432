RYNC · PRIVASI

Kebijakan Privasi

Terakhir diperbarui: 12 November 2026. Kebijakan ini menjelaskan data yang diproses ketika kamu memakai Rync, pemutar musik dan layanan dengar bersama yang dioperasikan oleh pemilik domain rync.zafir.my.

Data yang diproses Rync

  • Untuk room: kode room, ID perangkat acak, nama perangkat yang kamu masukkan, lagu aktif dan antrean, posisi/status playback, status kesiapan, serta pesan signaling WebRTC. Data ini diperlukan agar room dapat disinkronkan. Room dan metadata-nya dihapus setelah paling lama 3 jam tanpa aktivitas.
  • Untuk library di perangkat: favorit, playlist, riwayat, antrean solo, pencarian terbaru, preferensi tema, dan pengaturan audio disimpan di browser menggunakan IndexedDB atau localStorage. Data ini tetap ada sampai kamu menghapusnya atau membersihkan data situs di browser.
  • Untuk metrik teknis: durasi pencarian, persiapan audio, join room, dan antrean disimpan hanya di browser ini untuk membantu diagnosis. Rync tidak mengirim metrik tersebut ke server analitik.
  • Untuk file audio dan relay room: file yang kamu pilih tetap di perangkat untuk pemutaran solo. Jika host membagikan audio ke room, data audio dikirim melalui WebRTC atau relay server selama room aktif; file relay mengikuti batas pembersihan room 3 jam setelah aktivitas terakhir.
  • Untuk pencarian YouTube: istilah pencarian dan ID video dikirim ke server Rync lalu YouTube Data API. Hasil publik yang diperlukan untuk judul, channel, durasi, thumbnail, dan status pemutaran diproses untuk menampilkan hasil dan memastikan video boleh disematkan.

YouTube dan layanan pihak ketiga

Rync menggunakan YouTube API Services dan pemutar sematan resmi. Saat player dimuat atau video diputar, browser dapat berkomunikasi langsung dengan Google/YouTube dan mengirim informasi teknis seperti alamat IP, identitas browser, dan interaksi player sesuai kebijakan mereka. Rync memakai domain privacy-enhanced YouTube dan autoplay dimatikan sampai playback diminta.

Rync memeriksa status Made for Kids dan tidak menyematkan video yang ditandai demikian, karena Rync tidak dapat menonaktifkan seluruh tracking yang dilakukan player pihak ketiga. Kamu dapat membuka video tersebut langsung di YouTube. Pemutaran YouTube dijeda saat player atau tab browser tidak terlihat; Rync tidak menjalankan audio YouTube di latar belakang. Konten YouTube tetap tunduk pada Ketentuan YouTube dan Kebijakan Privasi Google.

Room dapat memakai broker MQTT publik EMQX untuk pesan realtime; bila tidak tersedia, Rync beralih ke polling server. Library MQTT dimuat dari cdnjs setelah persetujuan diberikan. Login Google bersifat opsional dan ditangani Firebase Authentication. Saat memakai layanan tersebut, Google/Firebase dapat memproses data sesuai kebijakan mereka.

Penyimpanan dan masa retensi

Cache pencarian Rync disimpan 5 menit di server, dengan cache jaringan yang dapat menyajikan hasil lama hingga 10 menit tambahan, dan 1 menit pada sesi halaman. Status izin pemutaran disimpan di memori server dan browser selama 5 menit. Metadata YouTube yang disimpan dari pencarian di library lokal akan dihapus dari fitur library setelah 30 hari; data API yang lebih lama harus diambil ulang atau dihapus. Room dan state-nya memiliki batas kedaluwarsa 3 jam setelah aktivitas terakhir.

Data library non-YouTube tersimpan pada perangkat sampai dihapus olehmu. Rync tidak menjual data pribadi. Data room tidak ditampilkan ke orang di luar room, kecuali informasi yang diperlukan untuk mengirim audio, signaling, dan sinkronisasi ke anggota room.

Kontrol dan penghapusan

Kamu dapat menghapus riwayat dari Library, menghapus favorit/playlist/file satu per satu, atau memakai Settings → Privasi & data untuk menghapus data Rync di browser ini sekaligus mencabut persetujuan. Membersihkan storage situs di pengaturan browser juga menghapus library lokal. Menghapus data browser tidak dapat menghapus salinan room yang masih aktif; room dibersihkan otomatis setelah masa kedaluwarsa.

Rync tidak meminta akses ke akun YouTube atau menyimpan kredensial YouTube. Jika kamu memakai login Google opsional, keluar melalui Settings untuk menghapus sesi autentikasi dari browser.

Perubahan dan kontak

Persetujuan akan diminta kembali saat cakupan kebijakan berubah. Untuk pertanyaan privasi, hubungi pemilik situs melalui kanal kontak pada rync.zafir.my. Informasi kontak langsung perlu ditambahkan oleh operator sebelum layanan dibuka untuk umum.
